BODH OS · DEVELOPMENT PREVIEW · 23 OCTOBER 2026

A desktop for learning.

Preview 0.36 adds native Quick Help and Study Tools, student project tools, an optional school AI connection and terminal security tools.

This is a development preview. Start in a new virtual machine. The Mac image is an experimental Linux build for the Intel MacBookPro15,2. It is not macOS and does not support Apple silicon. Physical hardware and school readiness remain unverified.

1. Choose your image

  • PC: BodhOS-PC-0.3.0-preview.36-amd64.iso
  • 2018 Intel MacBook Pro: BodhOS-MacBookPro15-2-0.3.0-preview.36-experimental-amd64.iso

Get the two matching .part01 and .part02 files for your image and the Guides ZIP from the same GitHub release. You do not need both PC and Mac downloads. The parts are split only to fit GitHub's asset size limit.

2. Assemble and verify

Windows: extract the Guides ZIP beside both download parts. Open Join PC ISO.cmd or Join Mac ISO.cmd. It checks both part hashes, joins them, then verifies the complete ISO. It does not install anything, format disks or change PowerShell settings. Existing mismatched output is never overwritten. Wait for the verified message.

macOS or Linux: open Terminal in the download folder. For PC:

cat BodhOS-PC-0.3.0-preview.36-amd64.iso.part01 BodhOS-PC-0.3.0-preview.36-amd64.iso.part02 > BodhOS-PC-0.3.0-preview.36-amd64.iso
shasum -a 256 BodhOS-PC-0.3.0-preview.36-amd64.iso

For the experimental Mac image:

cat BodhOS-MacBookPro15-2-0.3.0-preview.36-experimental-amd64.iso.part01 BodhOS-MacBookPro15-2-0.3.0-preview.36-experimental-amd64.iso.part02 > BodhOS-MacBookPro15-2-0.3.0-preview.36-experimental-amd64.iso
shasum -a 256 BodhOS-MacBookPro15-2-0.3.0-preview.36-experimental-amd64.iso

These Terminal commands write the named output file. Use a new folder without an existing ISO. On Linux, sha256sum can replace shasum -a 256. Compare the full result:

3. Try it safely

For a PC evaluation, create a fresh Debian 64 bit VirtualBox VM with two CPUs, 4 GB RAM, a new 32 GB virtual disk, VMSVGA graphics, 3D off, USB Tablet input and NAT networking. These are test settings, not minimum hardware requirements. Skip unattended installation. Attach your verified ISO and choose Try Bodh OS.

The live desktop and Classroom sessions are temporary. Install to the new empty virtual disk to keep work across reboots. Choose your own installed account and password. No test access or universal installed administrator password is included. Read the installation guide and recovery guide.

What to try

  • Quick Help: search ten offline guides for saving projects, backups, coding tools and shared computer sessions.
  • Study Tools: start a focus timer, pause it and try a break. The logout checklist is a reminder. It does not save files or make backups.
  • Student Files: create a new starter project, select a backup destination or make a verified assignment copy. Keep receipts and check backups. Copies are not encrypted.
  • Coding Apps: Python in Thonny, C and C++ in Geany, web and JavaScript starters, Arduino IDE, SQLite Browser, Git and GitHub CLI.
  • Assistant: get local coding guidance and open tools. A school can configure an optional Ollama compatible server. No AI model or server is bundled. Connecting sends your submitted conversation to that school server. Microphone input is offline and starts only when selected.
  • Appearance: Standard is the default. Reduced disables compositing. Glass is removed.
  • Rescue and updates: open diagnostics. Configure separate snapshot storage before enabling protected updates. Back up projects separately from system snapshots.
  • Security study: terminal only Nmap, Lynis, TShark, tcpdump, dig and OpenSSL. No Kali repositories, automatic captures or scanning services are added. Use the synthetic packet sample or a teacher approved lab.

Mac owners: read this first

The image targets only the 2018 Intel MacBook Pro identified as MacBookPro15,2. It retains T2 kernel 6.18.58-1-t2-trixie and a stock Debian fallback. The T2 packages are pinned and do not receive automatic community kernel updates. They need reviewed rebuilds.

Physical keyboard, trackpad, WiFi, Bluetooth, audio, suspend and other devices are not validated by VM boot tests. WiFi and Bluetooth need model specific Apple firmware supplied separately. The stock Debian installer may need an external keyboard and mouse. Read the included Mac hardware notes and their upstream guides before any installation.

Back up macOS and recovery data. Try a live hardware check first. Do not select whole disk erase for dual boot. No APFS modification, partitioning or firmware extraction runs automatically. This package is not a validated Mac dual boot installer.

Verification and limits

Image checks, live guest results and installed workflow results are tracked separately in the release validation record. Check its final status and the GitHub release notes before sharing.

Preview 0.35 performance results are historical. They do not measure this image. Real microphone recognition, configured AI model quality, physical Macs and PCs, Raspberry Pi, printers and a school pilot still need their own tests. Administrator and Classroom edition candidates are separate earlier images and are not refreshed by this desktop release.
