Downloading from a Mac?

Intel and Apple silicon DMG helpers

The Apple silicon helper prepares the PC image for x86_64 emulation only. There is no native ARM image. Both Mac helpers are unsigned developer previews pending real macOS launch checks.

Download Bodh OS for Windows

  1. Save the helper in a new folder.
  2. Double click it. It downloads the required files, joins them and checks the ISO. Allow about 6 GB of free space.
  3. Wait for SUCCESS - VERIFIED ISO READY. The folder opens with your ISO selected.

Use BodhOS-PC-0.3.0-preview.38-amd64.iso in VirtualBox. Do not choose either part file. No PowerShell commands are needed on Windows. The helper can resume an interrupted download. An earlier empty ISO is preserved and repaired.

Use it on a real PC

Read the USB and real PC installation guide or plain text version. Write the complete verified PC ISO to an empty USB with Rufus. Try the live desktop before installing. Back up and identify the correct target drive. Installation can erase the selected disk.

The generic PC guide is for Intel or AMD x86_64 computers. Physical hardware, Secure Boot and same drive dual boot remain unverified. Intel T2 Macs need the separate Mac notes.

Create your VirtualBox VM

  1. Click New, name it Bodh OS and select the verified ISO.
  2. Choose Linux → Debian 64 bit. Select Skip Unattended Installation.
  3. Allocate 4096 MB RAM, 2 CPUs and a new 32 GB virtual disk.
  4. Use VMSVGA, 128 MB video memory, 3D off, USB Tablet and NAT networking.
  5. Start and choose Try Bodh OS.
Try is temporary. Install to the new virtual disk to keep projects after shutdown. Installation asks for your own account and password. Read the installation guide and recovery guide. These VM settings are test settings, not minimum hardware requirements.
Manual download on Windows

Get PC part 1, PC part 2 and Guides ZIP. Extract the ZIP. Move both parts into the folder containing Join PC ISO.cmd. Open that helper and wait for SUCCESS. It verifies everything automatically.

The GitHub Source code ZIP and tar.gz are not OS images. Ignore those for installation. SHA256SUMS is for manual verification.

Joining files on macOS or Linux only

These commands are not Windows PowerShell commands. Get both matching PC parts in a new folder, then run:

cat BodhOS-PC-0.3.0-preview.38-amd64.iso.part01 BodhOS-PC-0.3.0-preview.38-amd64.iso.part02 > BodhOS-PC-0.3.0-preview.38-amd64.iso
shasum -a 256 BodhOS-PC-0.3.0-preview.38-amd64.iso

Expected SHA256: 43ab0eb7326c9833aa0ec5e5ec595dfef63340ded1b59af33cf30e2bb148f5b7. On Linux, sha256sum can replace shasum -a 256. Do not use an image that fails verification.

Experimental 2018 Intel MacBookPro15,2 image

Not macOS. Not Apple silicon. Physical Mac hardware and dual boot are unverified. Read the Mac hardware notes before testing.

cat BodhOS-MacBookPro15-2-0.3.0-preview.38-experimental-amd64.iso.part01 BodhOS-MacBookPro15-2-0.3.0-preview.38-experimental-amd64.iso.part02 > BodhOS-MacBookPro15-2-0.3.0-preview.38-experimental-amd64.iso
shasum -a 256 BodhOS-MacBookPro15-2-0.3.0-preview.38-experimental-amd64.iso

Expected SHA256: 094b84e45e729798a4a186c4816eb6e854d94fce7d04bd14e720a8231b6fae16. T2 packages are pinned and need reviewed updates. Owner supplied WiFi and Bluetooth firmware may be required. The stock installer may need external input devices.

If VirtualBox rejects the ISO

A zero byte file is not an ISO. Run the helper and wait for SUCCESS before attaching it. If VirtualBox says there is no bootable device, select the verified ISO under Settings → Storage → optical drive.
