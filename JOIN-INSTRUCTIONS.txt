BODH OS 0.3.0: PREPARE THE PC ISO

Download both PC parts and this Guides ZIP. Extract the ZIP beside both parts.
Neither part can boot by itself. Source code downloads are not the OS.

WINDOWS
Open Join PC ISO.cmd. Wait for SUCCESS - VERIFIED ISO READY.
The helper checks both parts, joins them and checks the complete ISO.
Or use Download-BodhOS-PC.cmd in a new empty folder for automatic downloading.
Keep 8 GB free. Existing mismatched files are preserved.

MACOS OR LINUX
Open Terminal in the folder containing both parts and ISO-SHA256SUMS.
Use a new folder without an existing output ISO. Run:

set -C
cat BodhOS-PC-0.3.0-desktop3-amd64.iso.part01 BodhOS-PC-0.3.0-desktop3-amd64.iso.part02 > BodhOS-PC-0.3.0-desktop3-amd64.iso
shasum -a 256 -c ISO-SHA256SUMS

On Linux, sha256sum -c ISO-SHA256SUMS can replace the last command.
All three entries must say OK. Stop if any check fails. Do not use a partial
or mismatched image. set -C prevents overwriting an existing output file.

USE THE ISO
For a new VM, follow installation.html. Choose Debian 64 bit and skip unattended
installation. On the previously tested Windows VirtualBox host use 1 CPU,
x2APIC off, I/O APIC on, VMSVGA and 3D off. Keep firmware unchanged after setup.
For a real x86_64 PC, read BodhOS-Install-on-PC.txt first and back up its files.
Booting a live desktop does not install the OS or keep work after shutdown.
Choose Install Bodh OS (simple setup) and review the target before disk writes.

This regular PC release does not add native Apple silicon or Raspberry Pi
support. The older experimental Intel Mac image is a separate archived build.
