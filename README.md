# Bodh OS downloads

A school desktop for learning and coding. Built on Debian 13.

## [Open the download page](https://adityajha2012.github.io/BodhOS-Downloads/)

### [Download for Windows PC](https://github.com/AdityaJha2012/BodhOS-Downloads/releases/download/v0.3.0-preview.38/Download-BodhOS-PC.cmd)

1. Save the helper in a new empty folder with 7 GB free.
2. Open it and wait for **SUCCESS - VERIFIED ISO READY**.
3. Use the completed **.iso** in VirtualBox or write it to a USB.

The helper downloads both parts, joins them and checks the result. No terminal commands needed. Part files and GitHub's Source code downloads are not bootable ISOs.

## Install

Follow the installation guide. Leave Domain name blank unless school IT supplies one. Leave the root password blank to make your first normal account an administrator. Review the target disk before approving writes. A simpler Preview 0.39 installer is being validated and is not published yet.
