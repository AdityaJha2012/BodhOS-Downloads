# Bodh OS downloads

Download Bodh OS 0.3.1 from https://adityajha2012.github.io/BodhOS-Downloads/

On Windows, save Download-BodhOS-PC.cmd in an empty folder and open it. Wait for SUCCESS. Use the complete ISO in a VM or on an existing Ventoy USB. Both parts are required for manual download.

This repository distributes the main PC edition. Parental OS and its guide are private. Server OS and the proposed AI Server edition are retired. Bodh ID cloud login is design only. Physical device support requires testing.
