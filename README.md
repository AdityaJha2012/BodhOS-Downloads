# Bodh OS 0.3.0 downloads

A school desktop for learning and coding. Built on Debian 13 and XFCE.

## [Open the download page](https://adityajha2012.github.io/BodhOS-Downloads/)

### [Download for Windows PC](https://github.com/AdityaJha2012/BodhOS-Downloads/releases/download/v0.3.0/Download-BodhOS-PC.cmd)

1. Save the helper in a new empty folder with 8 GB free.
2. Open it and wait for **SUCCESS - VERIFIED ISO READY**.
3. Select the completed **BodhOS-PC-0.3.0-desktop3-amd64.iso** in a new VM or write it to a USB.

The helper downloads both parts, joins them and checks the full ISO. The part files and GitHub's Source code ZIP are not bootable images. The download page has manual Linux and macOS instructions.

Latest desktop update: wallpaper based Auto styling, a cleaner taskbar, desktop app shortcuts, a Spectrum login screen and optional touchpad gestures.

Also included in 0.3.0: native MySQL Lab, a private database that starts on request, verified remote TLS, database backups and eight language connector examples. Java, PHP, Go and Node.js join the existing coding environments. The Bluetooth tray starts only if an adapter is present.

Personal student projects persist after installation. Temporary Classroom accounts reset after logout. Standard and Reduced effects remain available. Glass is removed.
