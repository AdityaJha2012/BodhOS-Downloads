Features and included software

WHAT THIS IS
Bodh OS is a school desktop built on Debian 13 and XFCE for x86_64 PCs.
This is the school desktop release. Larger deployments still need a local pilot.
The separate Intel MacBookPro15,2 image is experimental. It is not macOS.
Neither image supports Apple silicon or Raspberry Pi.
Signed Debian repositories are checked during image preparation. Read the
included security report for the check time and available package updates.
Run bodh-mac-compat for a model report. Identification does not certify drivers.

ACCOUNTS AND FAMILY TOOLS
Win + R opens Run. Ctrl + Shift + Esc opens Task Manager.
Local Parental Controls is available from Settings and Welcome.
A local administrator can set allowed days, hours and daily minutes for standard child accounts.
Rules are stored on the computer. Project files are kept when rules are removed.
Remote parent websites, server enrollment and generative AI are not included in 0.3.2.
Disable guest and Classroom access on family computers so children use their restricted accounts.


START HERE
Open Apps at the top left to find applications. Use Coding Apps to choose a language.
Open Welcome for links to this file, installation help and the main tools.
These guides are also in /usr/share/bodhos and at the top of the ISO.
The installed system keeps personal files and installed applications.
An ordinary live USB or live VM session is temporary. Back up your work.

DESKTOP AND EVERYDAY APPS
* A personal Bodh desktop, slim Apps bar, centered dock and desktop app shortcuts.
* Auto from wallpaper matches Dark or Light to the image, even during the day.
* Manual Light and Dark, plus a separate Scheduled mode using your local times.
* Thirteen original still wallpapers, including the lightweight blue Ocean image.
* Readable accents drawn from the wallpaper, or your own colour and presets.
* Per-user preferences and readable desktop labels over dark or mixed images.
  A short timer detects external wallpaper changes in about ten seconds.
  Native changes do not restart the panel. There is no resident theme process.
* Optional native touchpad gestures for workspaces, launcher, desktop, app
  switching and supported app zoom. They stay off without a detected touchpad.
  Physical multi-touch remains hardware dependent and has not been certified.
  The Touchégg backend is a hash-pinned upstream package, separate from Debian.
* Standard appearance and Reduced effects. Glass is not included.
* Thunar file manager, Mousepad text editor and XFCE terminal.
* Firefox ESR for browsing and online learning.
* LibreOffice Writer and Calc for documents and spreadsheets.
* VLC for media, GIMP for images and Evince for PDF documents.
* NetworkManager for network settings. Real WiFi support depends on hardware.
* Synaptic and Debian APT for installing and updating packages.

CODING TOOLS
* Python 3, Thonny IDE, pip and virtual environments.
* C and C++ with GCC, G++, Make and Geany.
* HTML, CSS and JavaScript with Geany and Firefox.
* Node.js, Java with the JDK, PHP and Go with matching Geany launchers.
  Coding Apps can run their starter programs without extra downloads.
* Arduino IDE. Extra board packages may require an Internet download.
* SQLite command line and DB Browser for SQLite.
* Native MySQL Lab with SQL editing, query results and CSV export.
* A private MariaDB engine starts only when requested and saves local tables.
  It listens only on this PC. Stop it when finished to free its RAM.
* Local database backup and restore with checksums and visible errors.
* Packaged local database examples for Python, C, C++, Node.js, Java, PHP,
  Go and shell. Browser and Arduino projects use a separate backend API.
* Remote MySQL and MariaDB connections with verified TLS and no plaintext
  fallback in the native client. Other connectors have their own TLS settings.
* Shell scripting with the terminal and Geany.
* Git and GitHub CLI. GitHub opens in Firefox. Sign in with your own account.
* Starter projects in your Projects folder. Coding Apps opens the matching tool.
  Use F5 in Thonny. Use Build and Execute in Geany for C and C++.

STUDENT WORK AND CLASSROOM ACCOUNTS
* Bodh Student Files creates projects, backups and assignment hand in folders.
* Persistent personal student accounts keep coding projects after reboot.
* A separate shared Classroom account clears its temporary home after logout.
  Never keep your only copy of a project in that shared account.
* Project backup and restore includes destination selection and integrity checks.
  Back up MySQL data separately using MySQL Lab. It is outside Projects.
* USB storage and file shares are available through the file manager.
  A particular school server, USB device or printer needs its own testing.
* Administrators can configure workspace limits and storage warnings.

BODH TOOLS
* Welcome links to apps, saved projects, recovery and these guides.
* Settings controls appearance, desktop reset and system information.
* Assistant gives local help and can open tools. It runs when opened.
* Offline voice commands use PocketSphinx and eSpeak NG when activated.
  Microphone compatibility and recognition quality need real hardware tests.
* Voice commands are recognised locally. Search requests open in Firefox.
  Only the requested search phrase is sent online. No generative AI is used.
* Study Tools and Quick Help provide local learning and troubleshooting help.

ADMINISTRATION, SECURITY AND RECOVERY
* School setup covers accounts, networking, updates, storage and USB enrollment.
* Persistent student accounts and temporary Classroom sessions stay separate.
* Debian security updates and administrator controlled update tools.
* Timeshift system snapshots and rollback. These do not replace project backups.
* Bodh Rescue offers diagnostics, backup and administrator authorized repair.
  Disk repairs can change a system. Read the recovery guide before using them.
* GRUB boot menu with live, installer and Rescue options, BIOS and UEFI support.
* UFW firewall tools, ClamAV malware tools and optional USBGuard enrollment.
  USBGuard blocking is not enabled in the factory image.
* Optional explicit school management enrollment. No factory management keys,
  test login or active remote access is included.
* Security lab commands: nmap, lynis, tshark, tcpdump, dig and openssl.
  These are Debian packages, not a Kali Linux installation or Kali repository.
  They are terminal tools. Use only on systems your teacher permits you to test.

HARDWARE AND LIMITS
The PC image includes Debian graphics and network drivers and common firmware.
This does not mean every GPU, WiFi chip, printer or laptop has been tested.
Proprietary NVIDIA installation is optional and needs separate verification.
The Intel Mac image adds a pinned T2 kernel for MacBookPro15,2. Physical Mac
devices and installation remain unverified. Read Mac-hardware-notes.txt first.
Apple silicon, Raspberry Pi and final custom kernel work are separate milestones.
No fixed minimum RAM is promised. Read this release's measured test results.
Virtual machine results do not prove physical hardware or school readiness.

INSTALL ON A REAL PC
Read BodhOS-Install-on-PC.txt beside this file before writing a USB or disk.
Try the live desktop first. Installing can erase the chosen drive.
Keep a separate backup and do not experiment on your only copy of important work.
