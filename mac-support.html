What we just added

The current ISO includes a small Mac model and architecture report. Run bodh-mac-compat to read it. We also expanded the development plan to cover Intel and Apple silicon. Model detection does not install drivers or prove that hardware works.

Your 2018 Intel MacBook Pro

The dedicated MacBookPro15,2 image remains experimental. Virtual machine boot and installation checks passed. Physical Mac devices and dual boot remain unverified.

Open the experimental Mac download section and read the hardware notes.

Other Intel Macs

Each model needs its own boot and driver review. T2 machines need additional integration. Older Intel machines can have different EFI requirements. The existing Mac image is not certified for every Intel Mac.

Apple's T2 model guide · T2 Linux feature status

Apple M1 and M2

These are the first targets for a future Asahi based Bodh OS port using Debian arm64. Boot software, kernel, graphics, firmware, audio safety, installation and recovery need integration and physical testing. No Bodh OS image is ready for these machines.

Apple M3 and later

Bodh OS does not support these models today. Upstream support varies by model and feature. The current M4 Pro status has no installer and major driver gaps. A generic ARM64 image does not add that support.

Before a future Mac release

We need results from the exact model for installation, recovery, repeated boot, graphics, input, networking, sound, charging and sleep. Those results will identify the tested version and image checksum. No physical Mac has passed the Bodh OS release checks yet.
