Historical package refresh: Bodh OS Preview 0.38, checked 24 October 2026.

10 package updates for PC. 9 for Mac. These were installed from signed Debian repositories into separate copies of the verified factory images. No available APT upgrades remained at the recorded check.

What changed

Both images refresh WebKitGTK, JavaScriptCore, Brotli, HEIF packages and timezone data. PC also updates Firefox ESR. The Mac image already had that Firefox version.

The updater now allows new dependencies needed by security and kernel updates and refuses package removals. A failed index refresh stops the update. Enabled snapshot protection must succeed before package changes.

The signed T2 index was reviewed and its package lock refreshed. The five pinned Mac packages, including its kernel, keep the same versions. The community repository is not enabled for unattended updates.

Update an installed copy

  1. Back up important student work.
  2. Open Bodh Settings, Updates, Install available updates. Authorize as an administrator.
  3. Read the result. Reboot after a kernel update. Automatic updates do not force a reboot.

Older installations can use this terminal command to include new security dependencies:

sudo apt-get --error-on=any update && sudo apt-get --no-remove --with-new-pkgs upgrade

Debian APT delivers Debian package updates. It does not automatically install new Bodh programs or this release's desktop updater changes. The Mac model report and Bodh application changes are in the new ISO. Installing that image is a separate migration that must preserve student backups.

What this does not establish

Applying every available package update does not mean every vulnerability has a fix. Physical Macs remain unverified. This release does not add Apple silicon support. Earlier Administrator and Classroom edition candidates were not rebuilt and should not be used as current security releases.

Build actions were updated to maintained Node 24 versions and pinned to commit hashes. ISO workflows remain manual.

Preview 0.39 firewall correction

An earlier candidate had Windows line endings in two firewall files. It was withheld. Both rebuilt images correct those files and check that the firewall is active with incoming connections denied.

On Preview 0.38 or an older installation, check the firewall rather than assuming it is active. Debian package updates alone do not apply this Bodh configuration fix. Back up your configuration, normalize its line endings and check the result. These commands preserve your existing rules and stop if a step fails.

(
set -eu
backup=$(sudo mktemp -d /var/backups/bodhos-firewall.XXXXXX)
sudo cp -p /etc/default/ufw /etc/ufw/user.rules "$backup/"
sudo sed -i 's/\r$//' /etc/default/ufw /etc/ufw/user.rules
sudo systemctl restart ufw
sudo ufw status verbose
)

Confirm Status: active and a default deny incoming policy. If a command fails, keep the backup and ask the administrator to inspect the error.
