Hardware and drivers

The PC ISO is for 64 bit Intel and AMD computers. It does not boot a CPU that only supports 32 bit. A PC running 32 bit Windows may still have a 64 bit CPU.

Current in Debian does not mean compatible with every device. Old hardware can lose vendor support, and very new hardware may need drivers outside this tested release. Check each school computer before installation.

Graphics choices

Intel and AMD use the kernel and Mesa open driver stack. NVIDIA uses Nouveau by default. If an exact card needs a supported proprietary driver, the administrator should review nvidia-detect and Debian's recommendation first. Test installation, reboot and any Secure Boot module signing on a disposable machine. Do not install unsupported legacy drivers or a vendor .run file across the lab.

Debian 13 removed the old proprietary NVIDIA Tesla 470 packages after upstream support ended. A higher driver version can also stop supporting older cards. No claim of every legacy or latest GPU is made. See Debian's NVIDIA guidance and Debian 13 release issues.

School hardware check

Start with live mode. Check display, keyboard, mouse, sound, wired networking and all required peripherals. Test WiFi and printers on the actual school network with permission. Test saved projects after reboot only on an approved installed test system.

Download the read only hardware helper. Open a terminal in its folder and run:

bash Bodh-Hardware-Check.sh

The helper prints local devices, loaded drivers, graphics renderer and basic service state. It installs nothing and does not scan the network. It is an observation tool, not a pass certificate. Keep raw reports private.

Physical GPU acceleration, school peripherals and Secure Boot remain unverified. The separate Intel T2 Mac image is experimental. There is no native Apple silicon or Raspberry Pi release. Obtain administrator approval before firmware or disk changes.
