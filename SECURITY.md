# Security

Use the verified regular PC 0.3.0 release linked in the README. It includes the existing firewall configuration correction, the signed Debian repository refresh and the new on-demand database tools. The separate experimental Intel Mac image remains at Preview 0.39.

The 27 October 2026 signed repository check found zero additional pending upgrades. It does not establish that every vulnerability is fixed. Keep installed systems updated and configure school policies deliberately.

APT upgrades Debian packages. It does not automatically deploy all new Bodh tools and defaults to an older installed image. Back up student data before changing releases. For the earlier firewall correction, use the [archived migration instructions](https://adityajha2012.github.io/BodhOS-Downloads/security-preview39.html), which preserve existing rules.

Read the [current security guide](https://adityajha2012.github.io/BodhOS-Downloads/security-updates.html) and [exact release evidence](validation/release030/RESULTS.txt). Physical hardware and school deployment require further testing. No universal device support or absence of future vulnerabilities is claimed.

Report the version, machine, error and reproduction steps. Do not publish passwords, enrollment bundles, private certificates or student files.
