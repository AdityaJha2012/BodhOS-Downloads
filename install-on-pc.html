Start with a VM or a live USB

VirtualBox

  1. Download and verify the complete ISO. Create a Debian 64 bit VM and skip unattended installation.
  2. Use two virtual CPUs, 2 GB or 4 GB RAM and a virtual disk of at least 32 GB. Attach the complete ISO as an optical drive.
  3. Choose Try Bodh OS to explore. Live session files are temporary.
  4. Choose Install Bodh OS when ready. Pick your own administrator name and password. Leave the domain blank unless your school supplies one.
  5. Select the VM disk, review the final partition changes and confirm. After installation, eject the virtual ISO and reboot. Keep the same BIOS or EFI setting.

A real school PC

  1. Get the school administrator's approval and back up the target computer.
  2. On an existing Ventoy USB, copy the complete ISO to its main data partition. Do not format the USB again.
  3. Use the computer's boot menu to select the USB, then choose Try Bodh OS. Check its display, keyboard, network, audio and USB devices.
  4. Only install after selecting and checking the intended target disk. Guided whole-disk installation erases that target. Ask an administrator to handle dual boot or a computer containing important data.
  5. Create a persistent account for student projects. The separate Classroom account is temporary and clears its home after logout.

No universal installed password is supplied. You set it during installation.
