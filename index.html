Download for Windows

Three simple steps

  1. Save the download helper in a new empty folder.
  2. Open it and wait for SUCCESS · VERIFIED ISO READY. It downloads both parts, joins them and checks the complete file.
  3. Use BodhOS-PC-0.3.1-amd64.iso in your VM or copy it onto an existing Ventoy USB.

The helper prepares a file. It does not install Bodh OS or format a drive. Follow the installation guide.

Manual download, Linux and macOS
  • PC ISO part 1
  • PC ISO part 2
  • Guides and joining helpers

Both parts are required. On Windows, put both parts beside Join PC ISO.cmd and open it. On Linux or macOS, use the instructions in the Guides ZIP. Select the complete .iso, never a .part file or the Source code ZIP.

Before using a real PC

Back up its files and try the live desktop first. Driver compatibility varies. VM checks do not certify WiFi, microphones, printers or touchpads on a physical computer.

The PC image is not a native Apple silicon image. The older experimental Intel Mac image has not been updated for this release. Read Mac limits.
