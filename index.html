Download for Windows PC

  1. Save the helper in a new empty folder. Allow 7 GB of free space.
  2. Open it. It downloads, joins and checks the ISO automatically.
  3. Wait for SUCCESS - VERIFIED ISO READY. Use the selected .iso file in VirtualBox or write it to a USB.

No commands or manual joining needed on Windows. If Windows blocks the download helper, use manual download. Never use an unfinished download.

Manual download and Linux

Download PC part 1, PC part 2 and the Guides ZIP.

On Windows, extract the ZIP, put both parts beside Join PC ISO.cmd and open it. Wait for SUCCESS. On Linux or macOS, the ZIP includes the exact join and checksum instructions.

GitHub limits individual file sizes, so the ISO uses two parts. Both are required. The helper produces one verified ISO. GitHub's Source code files are not the OS.

Mac choices and limitations

Intel and Apple silicon download helpers prepare the download. They do not install Linux. Apple silicon uses x86_64 emulation only. There is no native ARM image.

The separate 2018 MacBookPro15,2 image remains experimental. Physical Mac hardware and dual boot are unverified. Read compatibility notes.
