Install Bodh OS in VirtualBox

Use a new empty virtual disk. Your host computer's files are separate from this disk.

1. Prepare your ISO

Use the Windows download helper and wait for SUCCESS - VERIFIED ISO READY. Your file is BodhOS-PC-0.3.0-desktop3-amd64.iso.

2. Create the VM

  1. Click New. Name it Bodh OS and select the verified ISO.
  2. Choose Linux and Debian 64 bit. Select Skip Unattended Installation.
  3. Use 4096 MB RAM, 1 CPU and a new 32 GB virtual disk.
  4. In Display, use VMSVGA, 128 MB video memory and 3D off. Use USB Tablet for the mouse and NAT networking.

These are evaluation settings, not a certified hardware minimum. BIOS and EFI are both supported by the media. Keep the selected firmware unchanged after installation.

3. Choose simple setup

  1. Start the VM and choose Install Bodh OS. Try Bodh OS starts a temporary desktop instead.
  2. Choose language, region and keyboard. Enter your name, username and a password you will remember. This is your administrator account.
  3. Choose your time zone if asked. Network, domain, mirror and separate root password questions are skipped.
  4. For this new empty VM disk only, choose Guided → use entire disk, then the new 32 GB virtual disk. Choose all files in one partition for a simple evaluation.
  5. Review the disk summary. Choose Finish partitioning and write changes to disk, then approve only after checking the target is your new VM disk.
  6. Let installation complete. Follow the bootloader prompt if shown. Remove the ISO from the virtual optical drive when asked, then restart.
For a physical PC or a disk containing files, use the real PC guide. The installer still asks before writing partitions. There are no built in administrator test credentials.

4. Sign in and keep your work

Use the account and password you chose. Connect to the network from the taskbar. Open Coding Apps, edit a starter and save it in Projects. Restart and check the saved file remains.

Persistent student accounts keep projects. The separate temporary Classroom account clears its work after logout. Use Settings to set up school accounts and backups.

Advanced installation

Use Install Bodh OS (advanced) if you need network configuration during setup. Leave Domain name blank unless your school administrator supplies one. Leave the root password blank to give the first normal user administrator access through sudo.

If partitioning freezes

Power off the VM. Use 1 CPU, xAPIC mode and I/O APIC enabled. The tested VM had x2APIC disabled. In Windows PowerShell, the following optional command applies that CPU configuration to a powered off VM named Bodh OS. Change the name if yours differs. It does not format or change its disk. We observed freezing with two virtual CPUs on this Windows VirtualBox host. The ISO compatibility options alone did not resolve that configuration. No Windows security settings need to be disabled.

& 'C:\Program Files\Oracle\VirtualBox\VBoxManage.exe' modifyvm 'Bodh OS' --cpus 1 --x2apic off
& 'C:\Program Files\Oracle\VirtualBox\VBoxManage.exe' modifyvm 'Bodh OS' --apic on --ioapic on
