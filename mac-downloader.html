A simpler Mac download

Preview 0.38 download helpers for macOS. These DMGs prepare the existing ISO files. They do not install Bodh OS on your Mac.

Intel Mac

Download Intel helper DMG

Choose the PC image for an Intel Mac virtual machine. The app also offers the experimental image for the 2018 MacBookPro15,2. Native Intel Mac hardware compatibility is unverified.

Apple silicon Mac

Download Apple silicon helper DMG

There is no native Apple silicon Bodh OS image yet. This helper prepares the existing Intel PC image for x86_64 emulation only. Use an x86_64 emulator such as UTM in Emulate mode. Do not select ARM virtualization or VirtualBox on Apple silicon. Emulation can be slow. This is not an ARM installer.

How to use it

  1. Open the DMG and read START-HERE.html.
  2. Copy Bodh OS Downloader.app to Applications, then open it. It uses macOS system tools. No administrator password is needed.
  3. Choose an image and save folder. Allow 7 GB for PC or 8 GB for Intel Mac. macOS may ask permission to control Terminal.
  4. Keep the Terminal progress window open. Wait for SUCCESS - VERIFIED ISO READY. Finder shows the finished ISO.
  5. Select that ISO in your VM or emulator. Do not select either part file. Installing inside the VM keeps your work after shutdown.

The helper downloads both parts, checks their SHA256 fingerprints, joins them and verifies the complete ISO. Open it again to resume an interrupted transfer. Existing files are preserved if verification fails. It does not install Linux, repartition storage, erase a device or write a USB.

Developer preview

Both helpers are unsigned and not notarized. Their image format, resource hashes and executable permissions have been checked on Linux. Real macOS mounting, launch, permission prompts and downloads remain unverified.

If macOS blocks the app and you trust its source and checksum, read Apple's instructions to review it in System Settings, Privacy and Security. Never disable Gatekeeper globally. If macOS reports damage or malware, stop and use the manual download instructions.

Verify the DMG

Open Terminal and type shasum -a 256 , drag the downloaded DMG into the window, then press Return. Compare the result with its entry in SHA256SUMS. A checksum verifies integrity. It is not Apple notarization.
