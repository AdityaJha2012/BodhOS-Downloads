Updates and measured results

Bodh OS 0.3.1 uses the Debian kernel and signed configured Debian APT repositories. The preparation check installed Firefox ESR 153.6.0esr-1~deb13u1 and reported no pending upgrades at that time. This does not certify every vulnerability or hardware device.

Both BIOS and UEFI fresh installations and live boots passed. Tests covered saved projects, Classroom reset, native tools, backup integrity, GRUB repair, snapshot rollback and reboot. Native UI checks covered keyboard focus, small screens, wallpaper colours and missing microphone and connection errors.

QEMU KVM, UEFI, two virtual CPUs, std VGA, GL disabled, e1000 NAT. Each image has a separate pristine installation saved before first boot. Each case uses an independent disk copy. Old and new cases run as a simultaneous pair for each identical RAM and effects setting. No functional test VMs run during measurement. Paired host contention can affect timings. Onboarding is dismissed, with a terminal and measurement helper present. No management agent is installed. Default guest services remain. Three systemd boot measurements, five Settings window mappings and 300 seconds of idle sampling. Memory is MemTotal minus MemAvailable. Physical device performance and Parental edition performance are not certified by these PC measurements.
