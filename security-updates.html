Security and validation

The 0.3.0 PC image was refreshed against signed Debian repositories on 27 October 2026. No additional package upgrades were available at that check. Its new database and language dependencies come from Debian packages.

This does not mean every vulnerability is eliminated. Keep the installed system updated. Bodh OS uses APT and supports automatic security updates after administrator configuration.

The desktop and login update retains that package snapshot. The opt in Touchégg backend is a separately pinned upstream release with its checksum and origin recorded. It is not described as a Debian signed package. No production Bodh OTA or cloud login is enabled.

Database protection

The private MariaDB engine runs as the student, binds only to the local computer and grants its app account access to the student's lab database. It starts only when requested. Remote connections from MySQL Lab require TLS with a trusted certificate and matching hostname. SQL backups include integrity checks but are not encrypted.

School controls

Administrator approval protects system changes. Firewall rules block unsolicited incoming traffic. USBGuard requires deliberate device enrollment. ClamAV scanning and signature updates remain available. Temporary Classroom sessions clear their home and remaining student processes after final logout. Personal accounts keep their files.

Upgrading an older installation

APT updates Debian packages. They do not automatically replace every Bodh configuration or copy this release's native tools into an old installation. Keep backups and use a verified release for a fresh evaluation. For the older firewall line ending correction, follow the archived firewall migration instructions, which preserve your existing rules.

Evidence and limits

Read exact ISO checks, source identity and results. Separate VM tests cover local tools and remote database TLS. Hardware drivers, microphones, printers and school network policies still need direct checks.

There is no promise of universal hardware support or zero future bugs. Driver notes and hardware checklist.
